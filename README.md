# «Своя» — новый сайт клуба (v2)

Лендинг и демо-кабинет женского фитнес-клуба «Своя».
Сайт: https://egplatkov-spec.github.io/svoya-v2/

Собран на React + Vite + Tailwind CSS 4 с анимациями и компонентами из:

- **Anime.js** — заголовок по словам, счётчики цифр, «пружинное» появление плиток (`src/lib/anime.ts`)
- **Motion** — появление блоков при прокрутке, параллакс фото, переходы между страницами, гармошка вопросов
- **Kokonut UI** — перевёрнутые карточки, свайп-расписание, сетка виджетов, ползунок подтверждения, магнитная кнопка, фон из линий, печатающийся текст, «глитч»-текст, кольца активности (`src/components/kokonutui`)
- **Bklit UI** — анимированные графики: столбцы, кольцо, тепловая карта посещений (`src/components/charts`)

Кабинет — демо на ненастоящих данных: заявки и записи никуда не отправляются.
Рабочий сайт с оплатой и админкой — в отдельном проекте `svoya-app`.

## Запуск

```
npm install
npm run dev
```

После каждого `git push` в ветку `main` сайт сам пересобирается и выкладывается на GitHub Pages.
